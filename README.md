# Mini Redis

A lightweight Redis-inspired server built with asynchronous Rust and Tokio, implementing TCP-based client communication and shared in-memory state. Designed to explore concurrent request handling, protocol framing, and core Redis-like operations.

### Basic Functionalities
- GET/SET
- Shared state
- Concurrent client handling
- Protocol framing
- Echo server mode

### Future Scope
- Cache expiration and management
- PUB/SUB
- Command-line interface
- Performance benchmarking and optimization
